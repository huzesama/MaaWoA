遇到问题？欢迎来提 [ISSUE](https://github.com/huzesama/MaaWoA/issues) 反馈，我们会第一时间处理！更多好玩的功能正在路上，敬请期待 ✨

## ✨ 功能一览

- 🤖 **无人值守模式**：一键挂机自动处理飞机合同
  - 🛬 **机场IATA**：要处理哪个机场？告诉我们，直接帮你进去！
  - 💵 **超时贿赂**：处理超时了？帮你勾选贿赂！
- ✨ **特殊合同领取**：一键领取每日特殊入港的飞机合同
  - 🕹️ **自动处理**：合同太多占槽位？合同太少处理浪费时间？没事，给我们两个阈值我们帮你处理！
- 🧠 **端侧模型**：混合使用神经网络检测模型，Android端也可用喔！（⚠🔥高烧警告！）
- 💻 **多端适配**：无论你在哪个平台，我们都能陪你摸鱼~ 🐟
- 📡 **塔台续费**：正在开发中...
- ❄ **卡死重启**：正在开发中...
- ✍️ **更多功能**：更多功能持续更新中...
